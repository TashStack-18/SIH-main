# 🇮🇳 Bharat Safe Yatra — Phase 12: UX Interaction Flows

## 1. Primary User Journeys

### 1.1 Destination Exploration Flow
```
User navigates to /ai?destination=pangong-tso (or asks "Tell me about Pangong Tso")
   ↓
Conversation reflects verified high-altitude advice & dark sky photography
   ↓
Travel Context Workspace automatically switches to DESTINATION mode
   ↓
Shows hero imagery, altitude (4,350m), best visiting months (May–Sept)
   ↓
User clicks [ + Add to Itinerary ] → seamlessly handoffs to Itinerary Studio (/itinerary)
```

### 1.2 Route & Travel Telemetry Flow
```
User asks: "How do I get from Leh to Nubra Valley?"
   ↓
Yatra AI explains the route via Khardung La Pass (5,359m)
   ↓
Context panel transitions to MAP / ROUTE mode
   ↓
Displays 128 km distance, ~4.5h driving time, and 4 sequential checkpoints
   ↓
User clicks [ 🗺️ Explore 3D Geospatial Map ] → opens /map
```

### 1.3 Emergency & Safety Radar Flow
```
User asks: "What hospitals or helplines are in Leh?"
   ↓
Yatra AI provides Sonam Norboo Memorial Hospital (SNM) details
   ↓
Context panel shifts to SAFETY mode with direct [ 🚨 Call 112 Emergency ] button
```
